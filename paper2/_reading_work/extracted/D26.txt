Distributed H−/H∞ Attack Detection Based on  FDI for Multi-Area Load Frequency Control  Systems
This paper presents a distributed H−/H∞ attack detection scheme for multi-area Load Frequency Control systems, focusing on the False Data Injection attack detection problem.   The proposed method combines Lyapunov theory and Linear Matrix Inequalities (LMI) to design an attack detection system that minimizes conservatism and improves detection performance. A Voronoi-based Potential Field Algorithm for  UAV Coverage Path Planning in Arbitrary  Polygonal Areas
This paper introduces a novel Voronoi-based Full Coverage Path Planner for Unmanned Aerial Vehicles to efficiently cover arbitrary polygonal areas.  The proposed algorithm leverages a composite force model to optimize coverage paths, especially for complex non-convex environments. Innovation-Sequence-Based Adaptive Kalman Filtering  and Fault Detection for Integrated Navigation
This paper presents an innovation-sequence–driven adaptive Kalman filter (ISAKF) for detecting small, slowly drifting faults in integrated navigation systems.   The method adapts the Kalman filter by evaluating the innovation sequence and down-weighting suspicious channels, improving fault detection and isolation. Frequency-Domain Augmented Re-parameterized  YOLO for Medical Object Detection
This paper proposes a novel architecture, RFT-YOLO, for medical object detection that enhances the YOLOv8 framework. It introduces two key components: the Fourier Re-parameterized Convolution and the Re-parameterized C2f block. These innovations integrate both spatial and frequency-domain information, improving the model's ability to capture fine structural details and handle complex boundaries in medical images. This paper presents VSFNet, a novel semantic segmentation network for remote sensing images that integrates Visual State Space modeling with adaptive frequency-domain filtering.  The proposed method effectively addresses challenges such as multi-scale object distribution and complex textures, demonstrating superior performance on the LoveDA and Potsdam datasets.
