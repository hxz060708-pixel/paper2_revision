Remark 3. The static output feedback control is easy to implement, because it may be difficult to obtain all the state variables 
information to achieve the state feedback  [48]. The required conditions of static output feedback control are less conservative, 
because the system stability and control accuracy can be improved by adjusting static output feedback gains [48]. Besides, the 
controller design conditions can be relaxed by adjusting the uncertainty -dependent parameters in the controller. Moreover, the T -
S fuzzy model has nice ability to facilitate the controller design and it is more effective to design the controller in practice.
