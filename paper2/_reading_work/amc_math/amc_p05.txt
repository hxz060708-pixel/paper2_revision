Particularly, the output feedback control is often employed to handle the unavailable state variables, because it may be difficult 
to obtain the state variables information in the practical system [30, 31]. Thus, the output feedback control is more challenging due 
to the limited information of state variables. Moreover, the output feedback control is easy to implement, but some strict conditions 
should be considered in the system design [32 -34]. Thus, the static output feedback control is often employed to relax the design 
conditions in the practical system [35, 36]. With above reasons, this paper addresses the stochastic T-S fuzzy uncertainty-dependent 
static output feedback controller with measurable output error for a class of stochastic T-S fuzzy DGNNs . Compared with previous 
works, combining the Bernoulli probability distribution, T -S fuzzy model and uncertainty -dependent static output feedback 
switched control, the stochastic T-S fuzzy uncertainty-dependent static output feedback controller with measurable output error is 
designed based on the system knowledge by employing T -S fuzzy model in this paper. Additionally, the membership -function-
dependent Lyapunov functional has the better ab ility to obtain the less conservative stability conditions [37, 38]. Thus, the  
membership-function-dependent augmented Lyapunov functional with delay -dependent parameters is also designed to derive the 
less conservative stability conditions for the stochastic T-S fuzzy DGNNs in this paper. Overall, the objective in this paper is to 
design the stochastic T-S fuzzy uncertainty-dependent static output feedback controller with measurable output error for a class of 
stochastic T-S fuzzy DGNNs with additive uncertainties, mixed interval distributed delays and mismatched network noise, such

The contributions in this paper are presented as follows.  
(1) The additive uncertainties, mixed interval distributed delays and mismatched network  noise are all considered in the 
DGNNs. The DGNNs plant is approximated via premise variables and T -S fuzzy set. The T -S fuzzy infere nce and membership 
functions are employed to describe the DGNNs plant as average weighted sum of semi linear subsystems, such that the 
nonlinearities caused by additive uncertainties, mixed interval distributed delays and mismatched network  noise are handl ed 
effectively. The Bernoulli probability distribution is employed to describe the measurable output , and the random occurrence 
characteristic of sensor nonlinearity is described clearly.  
(2) The T-S fuzzy model and stochastic Bernoulli theory are employed to design the stochastic T-S fuzzy uncertainty-dependent 
static output feedback controller with measurable output error , and control design conditions are relaxed by designing different 
membership functions. The Bernoulli probability distribution is employed to describe the control input, and the random occurrence 
characteristic of packet dropouts from controller to actuator is described clearly. Applying the proposed controller to the stochastic 
T-S fuzzy DGNNs, the closed-loop system is finite-time bounded stable subject to 
( )12, , , ,c c L N   and the mixed H∞ passive  
performance is guaranteed.  
(3) The stability conditions are  derived by employing membership -function-dependent augmented Lyapunov functional and 
spectral norm scaling technique, the neural networks sensitivity/observability is enhanced and the proof process is simplified. The 
less conservative stability conditions  are derived by employing Schur complement, the block matrix with same structure as the 
original matrix is bulit and the computation process of LMIs is simplified. The controller gain matrix is determined by employing 
congruence transformation method, the computation complexity of solving LMIs is reduced and computer storage space is saved 
by designing congruence transformation matrices. 
The organization in this paper is presented as follows. The DGNNs plant is approximated by employing T-S fuzzy model and 
stochastic Bernoulli theory in Section 2. The stochastic T -S fuzzy uncertainty -dependent static output feedback controller with 
measurable output error  is designed in Section 3. The main results are presented for the closed -loop system in Section 4. The 
neural networks simulation examples are presented to show the effectiveness and advantage of the proposed method in Section 5. 
The conclusions are presented in Section 6.
